What happens

In this step.

Designed and coded from scratch

No templates or shortcuts: the interface, the API and the database are built to fit the problem.

One source of truth

Business logic lives in one place on the backend, so every device shows the same result.

Web and mobile together

A shared API can power the web app and the mobile app, as with Rannikon and Kuopas.

Check-ins along the way

Regular demos and feedback, so the product is shaped by the people who will use it.
