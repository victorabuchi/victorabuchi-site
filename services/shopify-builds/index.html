Service 03

E-commerce (Shopify) Builds

Custom Shopify themes built from the ground up in Liquid, not a modified template. The store looks and behaves like your brand, and you can still edit it yourself in the theme editor.

Start a project See how I work
  • Shopify Liquid
  • HTML / CSS / JS
  • Git / GitHub

What’s included

Everything it takes.

Online Store 2.0, done properly

JSON templates and sections, so you can rearrange pages in the theme editor without touching code.

Brand-specific pages

Beyond product and collection pages: new arrivals, curated outfits, collaborations and archives, each with its own template.

Everything shoppers expect

Faceted filtering, unit pricing, discounts in the cart, accelerated checkout, Shop Pay Installments and gift card products.

Search and recommendations

A search overlay with suggested products, plus related and complementary product recommendations.

Merchant-friendly settings

Colours, fonts and the suggested-products collection are theme settings, not hard-coded.

No build step

Plain CSS and JavaScript in the theme, so anyone can maintain it later.
