How I think

What I won’t compromise on.

Problems before technology

I start with what’s actually broken, then pick the tools. Sometimes I spot the problem first and build the fix before anyone asks.

From scratch, on purpose

No templates, no shortcuts. Every project is designed and coded to fit the problem, not the other way around.

Built to be depended on

Real workers, real deadlines, real problems that don’t disappear if the code is sloppy. Software has to work, not just demo well.

I stay after launch

Fixes, updates, and new features from someone who already knows the codebase.

A berry farm, and the software behind its season.

Every season Rannikon Puutarha employs over 300 seasonal workers from Ukraine, Cambodia, Vietnam, Nepal, and beyond, each tracking their hours on paper forms. I built the platform that replaced them: one system, every role, five languages.
